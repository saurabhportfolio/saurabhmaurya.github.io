# Saurabh Portfolio — GitHub Pages

A one-page editorial portfolio template inspired by modern creative portfolios. It is intentionally original, with placeholder projects and copy.

## Edit the site

### 1. Change your name
Open `index.html` and replace `PALI®` and the About/Contact copy.

### 2. Change projects
Open `script.js`. Edit the `projects` array with your real project titles, categories, years and image filenames.

### 3. Add real images
Put JPG/PNG/WebP files in `assets/`, then update each project's `image` path in `script.js`.

### 4. Change contact links
Update the email address and Instagram / LinkedIn / GitHub URLs in `index.html`.

## Publish on GitHub Pages

1. Create a GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save. Your site will be published at the GitHub Pages URL shown by GitHub.

No build step is required.
